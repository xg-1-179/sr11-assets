# sr11-assets

崩坏：星穹铁道互动卡「寰宇」的运行时素材仓，通过 jsDelivr CDN 直链引用。

## 目录

- `bgm/` 程序化渲染 / 自制音频（mp3）——不收官方 OST 原曲
- `scene/` 场景底图（自制 SVG / 程序化生成 / AI 生图）
- `avatars/` 头像与徽记（方形 webp/png，<=128px，尽量小）
- `ui/` 卡面用到的零散图（图标、纹理）

## 引用格式

`https://cdn.jsdelivr.net/gh/xg-1-179/sr11-assets@main/<路径>`

改了文件不必等 CDN 刷新，用 `@main` 即可；需要钉死版本时用 commit sha 代替 `main`。
